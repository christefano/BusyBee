# BusyBee
BusyBee is a Kanboard plugin that adds one-click questions about your projects, tasks, and subtasks, such as "What is late?" and "What is blocked?", to the top of Kanboard's dashboard pages. Admins can enable and disable questions and choose which icons, if any, are shown for questions and answers. Supports SortaFolders and its "My folders" page.
